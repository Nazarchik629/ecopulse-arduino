# EcoPulse — школьная метеостанция Arduino + Streamlit

Адаптивный сайт на Streamlit показывает температуру и влажность за последние 10 дней. Arduino UNO подключается по USB к компьютеру. Скрипт `bridge.py` на этом компьютере отправляет показания в Supabase, а опубликованный сайт Streamlit читает их из облака.

> Streamlit Cloud не может открыть COM-порт вашего домашнего компьютера. Поэтому оставьте компьютер и `bridge.py` включёнными, пока хотите собирать показания. Если выключить передачу, сайт останется опубликованным и покажет уже сохранённую историю.

## Что лежит в репозитории

- `streamlit_app.py` — сайт, графики, сводка и комментарии по показаниям.
- `arduino/ecopulse.ino` — скетч для Arduino UNO и датчика DHT11/DHT22.
- `bridge.py` — передача данных от COM-порта компьютера в облачную базу.
- `supabase_setup.sql` — таблица и правила доступа для Supabase.
- `requirements.txt` — зависимости приложения и USB-передатчика.
- Светодиодная матрица `1088BS` с фотографии — дополнительный экран, не датчик; для текущего сайта она не нужна.

## Часть 1. Собрать датчики

Нужны: Arduino UNO, макетная плата, провода-перемычки, USB-кабель с передачей данных и ваш датчик температуры/влажности DHT11 или DHT22. Для отдельного DHT с четырьмя ножками нужен резистор 10 кОм; у трёхконтактного модуля он часто уже установлен.

Перед подключением отключите Arduino от USB. Подключения ниже подходят для DHT11/DHT22 с четырьмя ножками; у готового модуля обычно три контакта с подписями `S`, `+`, `-`.

### DHT11 или DHT22 с четырьмя ножками

Поверните датчик решёткой к себе, ножки вниз. На распространённой версии контакты слева направо: `VCC`, `DATA`, `NC`, `GND`.

1. `VCC` датчика → `5V` Arduino.
2. `DATA` датчика → цифровой контакт `D2` Arduino.
3. `NC` не подключать.
4. `GND` датчика → `GND` Arduino.
5. Поставить резистор 10 кОм между `VCC` и `DATA` (подтяжка).

Если на корпусе/модуле подписаны контакты, ориентируйтесь по маркировке, а не только по положению ножек. Модуль с тремя контактами часто уже содержит нужный резистор. В скетче сейчас выбран DHT11. Если у вас DHT22, замените в `arduino/ecopulse.ino` строку `#define DHT_TYPE DHT11` на `#define DHT_TYPE DHT22`.

### Матрица 1088BS с фотографии

Маркировка указывает на матрицу из 64 светодиодов (8 × 8), а не на датчик освещённости. Для её управления нужна совместимая плата-драйвер, например комплект матрицы с MAX7219. На фото видна отдельная матрица без драйвера, поэтому пока не подключайте её напрямую к Arduino; сначала нужны точная распиновка и драйвер, соответствующий типу матрицы. [Техническое описание 1088BS](https://www.ledtoplite.com/uploadfile/2017/1088/TOP-CA-1088BS.pdf)

### Загрузить программу в плату

1. Установите Arduino IDE с официального сайта Arduino.
2. В IDE откройте менеджер библиотек и установите **DHT sensor library by Adafruit**. Если IDE предложит установить зависимость **Adafruit Unified Sensor**, согласитесь.
3. Откройте `arduino/ecopulse.ino`.
4. Подключите Arduino UNO USB-кабелем к компьютеру.
5. В Arduino IDE выберите **Инструменты → Плата → Arduino UNO** и порт, который появился после подключения.
6. Нажмите **Загрузить**. В скетче данные идут в формате `температура,влажность` раз в 10 секунд.

Проверка: откройте **Инструменты → Монитор порта**, выберите `9600 бод`. Должны появляться, например, строки `24.0,41.0,68`. Закройте монитор порта перед запуском `bridge.py`, иначе две программы будут одновременно занимать COM-порт.

## Часть 2. Создать облачную базу Supabase

1. Создайте проект в Supabase и сохраните его пароль в надёжном месте.
2. В PowerShell создайте длинный случайный токен устройства:

```powershell
$deviceToken = [guid]::NewGuid().ToString("N") + [guid]::NewGuid().ToString("N")
$deviceToken
```

Скопируйте выведенную строку. Она понадобится для базы и для скрипта передачи. Не публикуйте её.

3. В панели проекта откройте **SQL Editor → New query**. Скопируйте текст `supabase_setup.sql` и вставьте его в SQL Editor Supabase. Замените `ЗАМЕНИТЕ_ЭТО_НА_СЛУЧАЙНЫЙ_ТОКЕН` на свой токен прямо в редакторе Supabase, между одинарными кавычками, затем нажмите **Run**. **Не сохраняйте изменённый SQL-файл и не загружайте токен в GitHub** — в репозитории оставьте строку-заполнитель.
4. Откройте **Project Settings → API** (или раздел API Keys в новой панели) и скопируйте **Project URL** и публичный **Publishable key** (`sb_publishable_...`). В старом интерфейсе ключ может называться `anon`.
5. Не копируйте `service_role`/`secret` key: он обходит RLS, здесь он не нужен.

Таблица включена с RLS. Сайт может читать измерения, а загрузчик добавляет их только через RPC-функцию с секретным токеном устройства. Прямую публичную запись в таблицу SQL запрещает.

## Часть 3. Запустить передачу с компьютера

Установите Python 3.11 или новее. Откройте PowerShell в папке репозитория (внутри `ECOLOGY-SCRIPT`) и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:SUPABASE_URL = "https://ВАШ-ПРОЕКТ.supabase.co"
$env:SUPABASE_PUBLISHABLE_KEY = "ВАШ_PUBLISHABLE_КЛЮЧ"
$env:ECOPULSE_DEVICE_TOKEN = "ТОТ_ЖЕ_ТОКЕН_ЧТО_ВСТАВИЛИ_В_SQL"
$env:ECOPULSE_SERIAL = "COM5"
.\.venv\Scripts\python.exe bridge.py
```

Подставьте настоящий Project URL, Publishable key, сохранённый токен и свой COM-порт. Порт можно посмотреть в Arduino IDE в **Инструменты → Порт**. Arduino передаёт измерения раз в 10 секунд, а `bridge.py` сохраняет в облаке одно измерение в минуту. Не закрывайте это окно PowerShell во время сбора. Дневная сводка обновляется примерно раз в 15 секунд.

Переменные среды задаются заново в каждом новом окне PowerShell. Не добавляйте ключи в `streamlit_app.py`, `bridge.py`, README, скриншоты или GitHub.

## Часть 4. Посмотреть сайт на компьютере

Для локального просмотра откройте второе окно PowerShell в папке `ECOLOGY-SCRIPT`. Задайте в нём `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY`, затем запустите:

```powershell
.\.venv\Scripts\streamlit.exe run streamlit_app.py
```

Браузер откроет локальный адрес, обычно `http://localhost:8501`. Для соединения с базой задайте в этом PowerShell те же `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY` перед запуском. Без настроек приложение покажет демо-данные.

## Часть 5. Выложить на GitHub

1. Создайте новый пустой репозиторий GitHub, например `ecopulse-arduino`.
2. Загрузите в него **содержимое папки `ECOLOGY-SCRIPT`**: `streamlit_app.py`, `requirements.txt`, `bridge.py`, `supabase_setup.sql`, `.gitignore`, `README.md` и папку `arduino`.
3. Не загружайте `.venv`, `.env`, `.streamlit/secrets.toml`, ключи или личные пароли. `.gitignore` уже исключает типовые локальные секреты.

Самый понятный способ без команд Git: в новом репозитории нажмите **Add file → Upload files**, перетащите файлы проекта и нажмите **Commit changes**. Если веб-интерфейс не сохраняет вложенную папку, создайте файл `arduino/ecopulse.ino` через **Add file → Create new file** и вставьте туда содержимое скетча. `.gitignore` — скрытый файл: если загрузчик его не показывает, создайте его через **Add file → Create new file** с именем `.gitignore` и вставьте содержимое из папки проекта.

## Часть 6. Опубликовать через Streamlit Community Cloud

1. Войдите на Streamlit Community Cloud через GitHub и разрешите доступ к репозиторию.
2. Нажмите **Create app** и выберите репозиторий `ecopulse-arduino`, ветку `main`, файл приложения `streamlit_app.py`.
3. В **Advanced settings → Secrets** вставь TOML. Первые две строки нужны для базы. Последние три подключают Gemini:

```toml
SUPABASE_URL = "https://ВАШ-ПРОЕКТ.supabase.co"
SUPABASE_PUBLISHABLE_KEY = "ВАШ_PUBLISHABLE_КЛЮЧ"

AI_PROVIDER = "gemini"
AI_API_KEY = "НОВЫЙ_КЛЮЧ_ИЗ_GOOGLE_AI_STUDIO"
AI_MODEL = "gemini-flash-latest"
```

4. Нажми **Deploy**. После сборки Streamlit покажет публичную ссылку на сайт.
5. Если сайт уже опубликован: открой его, нажми **Manage app → Settings → Secrets**, добавь эти же строки и сохрани настройки.
6. Проверь ссылку с телефона. При добавлении коммита в GitHub Streamlit Community Cloud автоматически обновляет приложение.

Сначала открой Google AI Studio → **API keys**, отзови ключ, попавший на скриншот, и создай новый. Вставь только новый ключ в `AI_API_KEY` в Secrets. Код обращается к Gemini напрямую через его `generateContent` API, поэтому `AI_API_URL` для Gemini не требуется. Модель `gemini-3.8-flash` указана как пример; доступные модели и условия квоты проверь в AI Studio.

В Secrets после публикации можно попасть через сайт: **Manage app → Settings → Secrets**. Если приложение ещё не развернуто, вставь настройки при первом создании: **Advanced settings → Secrets**.

**Не вставляй ключ ИИ в `streamlit_app.py`, README, SQL-файл, сообщение или GitHub.** Вставляй его только в поле **Secrets** Streamlit Cloud. Для других провайдеров код также умеет OpenAI-совместимый Chat Completions API: задай `AI_PROVIDER = "openai_compatible"`, а также `AI_API_URL`, `AI_API_KEY` и `AI_MODEL`.

## Важное про 10-дневную историю

График начинает показывать реальные данные после первой отправки. Полные 10 календарных дней появятся после сбора в течение 10 дней. Компьютер и `bridge.py` должны быть включены и подключены к интернету. Облачный сайт можно открыть с другого устройства, но Arduino остаётся подключённой к компьютеру, который пересылает показания. В базе хранится одно измерение в минуту; SQL-представление `daily_readings` считает дневные среднее, минимум и максимум по часовому поясу Asia/Qyzylorda.

Фон `#06080F`, поверхность `#0D121F`, основной текст `#E8ECF4`, вторичный текст `#7C86A0`; температура `#FF4D6D`, влажность `#27E1FF`. Заголовки используют Playfair Display, основной текст — DM Sans. Шкала: крупный заголовок 64–112 px (на телефоне 64 px), заголовок раздела около 36 px, заголовок блока 22 px, основной текст 15–16 px, подписи 10–12 px. Макеты из `ECOLOGY-DESIGN` служат визуальным ориентиром.
